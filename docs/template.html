Reading these plots

Each diagonal marginal is normalized to unit area. Contours enclose 50% and 90% of the smoothed two-dimensional sample density. Grey lines mark the injected parameters. Plots use up to 1000 retained equal-weight samples per run; thinning can hide rare modes. The reference is a sampled posterior, and visual agreement alone does not establish convergence.
